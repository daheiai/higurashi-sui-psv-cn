## 这是什么

《寒蝉鸣泣之时 粹》（ひぐらしのなく頃に粋，PlayStation Vita）的**简体中文汉化补丁（测试版）**，由**多金喵喵汉化组**制作。

补丁以 **rePatch / Mod** 方式加载，**不修改游戏本体**，**完全免费**。

- 游戏编号（Title ID）：`PCSG00517`
- 支持平台：Vita3K 模拟器、已破解 PSV 实体机（rePatch 插件）
- 支持语言：简体中文（zh-CN）
- 官网与下载：[hanchan.daheiai.com/#downloads](https://hanchan.daheiai.com/#downloads)

> ⚠️ **这是测试版**。全路线通关、存读档、答题与其他功能尚未完成全面验证，本版**不宣称**全游戏无漏译、无排版问题或兼容所有转储与设备。

## 版本对照

| 补丁版本 | 发布日期 | 适用环境 | 说明 |
| --- | --- | --- | --- |
| **V0.2 测试版** | 2026-10-09 | PSV 实体机专属 | 当前主推。使用玩家自己的原版 EBOOT，**不含** `eboot.bin` 与模块文件，走 rePatch |
| V0.1 测试版 | 2026-10-07 | Vita3K 模拟器专属 | 含配套 `eboot.bin` 与 `sce_module`，三项文件必须配套使用 |

> 两版**不能混用**：实体机请用 V0.2，模拟器请用 V0.1。把 V0.1 的文件套到实体机上，或把 V0.2 当模拟器升级包用，都可能起不来或崩溃。
