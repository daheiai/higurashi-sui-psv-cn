# 实体机（rePatch）安装指南

适用于**已破解的 PlayStation Vita**，通过 **rePatch** 插件加载补丁，**不修改游戏本体**。

对应版本：**V0.2 测试版（实体机专用）**

## 前置条件

- 已破解的 PSV，已安装并启用 **rePatch 插件**（用「自动插件2」安装也可以）
  - 手动安装：把 `repatch.skprx` 放到 `ur0:tai/`，在 `ur0:tai/config.txt` 的 `*KERNEL` 下另起一行写 `ur0:tai/repatch.skprx`，保存后**重启主机**
  - 请使用 **rePatch 3.0.1 或更新版本**。作者测试 3.0 时，卡带不会加载 rePatch 目录里的 `eboot.bin`
- 游戏本体《寒蝉鸣泣之时 粹》，编号 `PCSG00517`（正版卡带 / 官方下载版 / NoNpDrm 均可）

## 步骤

1. 先确认**原版游戏能正常启动**，然后完全退出游戏。**先备份存档和旧补丁。**
2. 如果装过 V0.1 或其他测试包：先把整个 `ux0:rePatch/PCSG00517/` 旧目录**移出 rePatch 备份，或备份后删除**。
   - ⚠️ **不能直接覆盖**：残留的旧 `eboot.bin` 可能导致崩溃。
3. 用 **VitaShell** 把补丁包里的 `rePatch/PCSG00517/` 文件夹复制到 `ux0:rePatch/`。
4. 确认最终路径为：

   ```
   ux0:rePatch/PCSG00517/patch.rom
   ```

   该目录内**应只有本包的 `patch.rom`**，不要混入旧 `eboot.bin` 或 `sce_module`。
5. 启动游戏，**出现中文补丁说明画面**即表示资源补丁已加载。

## 注意

- **不要**放入 `sce_sys`；**不要**覆盖或删除原版 `data.rom`、原版 `eboot.bin`。
- 本包**不提供** `eboot.bin`，也不提供任何模块文件——实体机使用玩家自己的原版 EBOOT。
- 因此**不包含**修改版 EBOOT 里的系统提示、答题选项等译文，相关位置可能仍显示日文。
- 不要把本包与 V0.1（模拟器包）的文件混用，也不要删除原游戏目录或存档。
- 建议**先使用新的存档位**，测试中文剧情、保存后读取、答题题面与选项及菜单显示。

## 回滚 / 卸载

1. 完全退出游戏。
2. 删除 `ux0:rePatch/PCSG00517/` 整个文件夹。

原游戏文件没有被本包修改。不要恢复曾导致崩溃的旧补丁 EBOOT。

## 出问题时请提供

主机系统版本、游戏版本、rePatch 版本、异常发生位置与截图；若崩溃，请保留 `ux0:data/` 下对应的新 `psp2core-*.psp2dmp` 文件。
