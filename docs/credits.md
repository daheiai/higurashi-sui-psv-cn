# 鸣谢

这个补丁能跑起来，离不开前人的开源工作与汉化成果。

- **shin-tl / shin-translation-tools** —— PSV 版《粹》的解包与打包链路，本项目据此提取 `main.snr` 文本与资源。
- **fnt4-tool** —— PSV 字体（FNT4）处理与重建。
- **rePatch** —— PSV 实体机的补丁加载插件，实体机方案的基础。
- **Vita3K** —— 开发与测试使用的 PSV 模拟器。
- **VitaShell** —— 实体机安装时的文件管理工具。
- **母项目 Switch《奉》汉化** —— 本项目的译文与流程大量复用自同组的 Switch 版汉化成果。
- **07th Expansion / Entergram** —— 原作与发行方。本项目为非官方爱好者作品，与上述公司无任何关联。
- **反馈问题的玩家（含 B 站网友）** —— 实体机专用版 V0.2 正是来自玩家反馈；感谢提供截图、复现过程与崩溃日志。
