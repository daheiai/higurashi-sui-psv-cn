# 模拟器（Vita3K）安装指南

适用于 **Vita3K** 模拟器。

对应版本：**V0.1 测试版（模拟器专用）**

> 适用游戏编号 `PCSG00517`。模拟器请使用 V0.1；**实体机请改用 V0.2 测试版**，不要套用本包。

## 前置条件

- Vita3K 模拟器
- 游戏本体《寒蝉鸣泣之时 粹》已安装，编号 `PCSG00517`

## 步骤

1. 解压下载的补丁包。
2. 确认游戏本体已经安装并能正常运行，然后**完全退出 Vita3K**。
3. 打开 **Vita3K 数据目录**，进入 `ux0/app/PCSG00517/`，确认里面有 `data.rom` 和 `eboot.bin`。
4. **备份**原有 `eboot.bin`、`patch.rom`（如有）和 `sce_module` 文件夹。
5. 把补丁包 `Emulator_Mod_模拟器直接加载/` 里的 `patch.rom`、`eboot.bin` 和 `sce_module` 文件夹**一起**复制进去：
   - `sce_module` **合并**，不要删除原文件夹，同名文件覆盖；
   - **不要删除 `data.rom`**，也不要把补丁放进存档目录。
6. 启动游戏，看到**中文汉化说明画面**即表示补丁已加载。

## 注意

- `patch.rom`、配套 `eboot.bin` 与 `sce_module/stero1d.suprx` **三项必须配套使用**，只换其中一部分可能起不来。
- 不要把 `Emulator_Mod_模拟器直接加载` **文件夹本身**套在游戏目录内。
- 已安装过 021 / 022 包的模拟器用户，升级到本版时**只需覆盖 `patch.rom`**。
- 本包基于开发者已验证的 `PCSG00517` 转储制作，不同转储版本未全部验证；其他游戏编号与 PSV 实机不在本次验证范围内。若你的本体版本不同，**请勿无备份强行覆盖**。
- 本包**不含游戏本体**，请自行购买正版并准备合法转储。

## 回滚 / 卸载

1. 关闭模拟器。
2. 恢复安装前备份的文件；原来没有 `patch.rom` 时，把它移走即可。

**不要删除存档。**

## 出问题时请提供

Vita3K 版本、游戏本体版本、异常发生位置、截图或日志。请勿公开分享游戏本体、私密配置或个人存档信息。
